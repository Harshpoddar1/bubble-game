# 🫧 Bubble Number Clicker

A fast-paced 60-second browser game. A random number is shown on screen — click the bubble that matches it before time runs out. Every correct click gives you points.

Built with **HTML, CSS and JavaScript** (no libraries or frameworks).

## 🎮 How to Play

1. Open the game and start the timer.
2. A target number is displayed.
3. Find and click the bubble with the same number.
4. Correct click = points. Keep going until the 60 seconds are over.
5. Try to beat your own high score!

## ✨ Features

- 60-second countdown timer
- Random target number every round
- Score tracking
- Simple, clean UI

## 🛠️ Tech Stack

| Part | Used for |
|------|----------|
| HTML | Game structure |
| CSS | Bubble styling and layout |
| JavaScript | Game logic: timer, random numbers, score |
